# Scope and roadmap

## Current scope

- Go source and unit tests.
- Dockerfile and package metadata retained as demonstration assets.
- GitHub workflow assets retained for learning/review.

## Out of scope

- Publishing images, operating a registry, deploying containers, or connecting cloud infrastructure.
- Representing the workflow as a production release process.
- Adding credentials, external tokens, or secrets.

## Review points

Confirm the intended learning outcomes, public audience, dependency hygiene, and whether the workflow should remain a small example or evolve through separately approved work.
